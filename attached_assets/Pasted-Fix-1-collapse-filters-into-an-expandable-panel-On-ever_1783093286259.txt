Fix 1, collapse filters into an expandable panel
On every screen where search and filters were recently added, the State Admin Trips page, State Admin Wallet page, State Admin Trip Admins page, Trip Admin Trips page, Trip Admin Vehicles page, Trip Admin Drivers page, and the Stakeholder wallet page, the filter controls currently sit permanently visible below the search bar, taking up too much vertical space before any actual list content appears.
Change this pattern on all of these screens. Keep the search input always visible at the top, exactly as it is now. Below it, add a single button labeled Filters, with a small badge showing the count of currently active filters if any are applied, for example Filters with a small 2 badge if a date range and a status are both active. Tapping this button expands a panel below it containing all the existing filter controls for that screen, date presets, custom range, status pills, vehicle type filters, whatever already exists on each specific screen. Tapping the Filters button again, or tapping outside the panel, collapses it back down.
When collapsed, if any filters are currently active, show a small summary row instead of nothing, for example a single line reading something like Last 30 days, Completed with a clear X to reset all filters at once, so the user can see at a glance what is currently applied without needing to expand the panel again.
Use a smooth expand and collapse animation consistent with the LayoutAnimation pattern already used elsewhere in this app for similar expand and collapse behavior.
