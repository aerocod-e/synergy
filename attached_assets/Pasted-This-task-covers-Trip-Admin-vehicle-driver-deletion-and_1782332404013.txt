This task covers Trip Admin vehicle/driver deletion and State Admin Trip Admin deletion. Follow all steps in order.
Step 1 -- Backend: driver soft-delete endpoint
In artifacts/api-server/src/controllers/driverController.ts, add a deleteDriver function:

DELETE handler for /drivers/:id
Trip Admin only
Validates the driver exists, is not already soft-deleted, and was created by the calling Trip Admin (created_by = req.user.userId) -- return 403 if not owned
Checks whether the driver has any active trips (status IN ('created', 'in_transit')) -- if yes, return 400 "Cannot delete a driver who has active trips"

Returns 200 with message "Driver has been removed successfully"
