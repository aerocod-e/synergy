This is a full regression test pass covering everything built and fixed in Stage 3A. Do not make any changes. Run every test in order and report results.
For all frontend tests: perform live App Testing in a fresh browser session, navigating only by tapping real visible UI elements. Never navigate by typing or editing a URL to jump between in-app screens. Do not test browser Back navigation in this session. If a screen cannot be reached by tapping a visible element, report that as a failure.

SECTION A -- Data Integrity (backend checks only)
A1. Confirm the trips table has no vehicle_number column. Query information_schema.columns and report.
A2. Confirm all trips have a non-null vehicle_id and a non-null trip_code in the format SYN-YYYY-NNNNNN.
A3. Confirm all wallet_ledger entries have a valid wallet_id, trip_id, and trip_fee_id (no orphaned rows).
A4. Confirm wallets.total_collected reconciles correctly for every wallet using SUM(amount) directly on wallet_ledger (no CASE statement -- amounts are already signed). Report any wallet where these do not match.
A5. Confirm no users have role outside the four valid values (super_admin, state_admin, trip_admin, stakeholder). Soft-deleted users are acceptable as long as deleted_at IS NOT NULL.

B1. Login as Super Admin. Confirm the landing screen is the Dashboard tab, not a trip list.
