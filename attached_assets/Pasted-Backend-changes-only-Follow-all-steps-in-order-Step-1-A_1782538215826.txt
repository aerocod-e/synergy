Step 1 -- Auto-add new stakeholders to all vehicle types at ₦0
In artifacts/api-server/src/controllers/userController.ts, find the createUser function, specifically the block that creates a new stakeholder entity when stakeholderName doesn't match an existing one.
After the stakeholder entity and wallet are created, add a block inside the same transaction that inserts ₦0 rates for every active vehicle type on the active pricing chart:
sqlINSERT INTO pricing_chart_stakeholder_rates (pricing_chart_id, stakeholder_id, vehicle_type_id, amount)
SELECT pc.id, $newStakeholderId, vt.id, 0
FROM pricing_charts pc
CROSS JOIN vehicle_types vt
WHERE pc.is_active = true
AND vt.is_active = true
