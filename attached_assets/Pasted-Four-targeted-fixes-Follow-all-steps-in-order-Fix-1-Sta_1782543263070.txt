Fix 1 -- State Admin native landing tab
The unstable_settings approach works on web but not on physical iOS. Use a different approach.
In artifacts/mobile/app/(stateadmin)/_layout.tsx, add a useEffect that runs once on mount and redirects to the wallet tab if the current route is not already wallet:
tsximport { useEffect } from 'react';
import { useRouter, useSegments } from 'expo-router';

// Inside the layout component:
const router = useRouter();
const segments = useSegments();

useEffect(() => {
  const currentRoute = segments[segments.length - 1];
  if (currentRoute !== 'wallet') {
    router.replace('/(stateadmin)/wallet');
  }
}, []);
Keep the unstable_settings export as well since it helps on web. The useEffect redirect handles native.
