TASK 2: Auth Endpoints + Middleware

Create src/utils/tokenUtils.ts
  Two functions:
  
  generateTokens(userId: string, role: string, 
    entityType: string | null, entityId: string | null)
    Returns:
      accessToken: JWT signed with JWT_SECRET, 
        expires in 15 minutes
        payload: { userId, role, entityType, entityId }
      refreshToken: JWT signed with JWT_REFRESH_SECRET, 
        expires in 7 days
        payload: { userId }

  verifyAccessToken(token: string)
    Returns decoded payload or throws error

---

Create src/middleware/auth.ts
  Middleware function: authenticateToken
    Reads Authorization header: "Bearer <token>"
    Verifies token using verifyAccessToken
    Attaches decoded payload to req.user
    Returns 401 if token missing or invalid

---

Create src/middleware/roleGuard.ts
  Middleware factory: requireRole(...roles: string[])
    Returns middleware that checks req.user.role 
    is included in the allowed roles array
    Returns 403 if role not allowed
    Usage example: 
      router.get('/something', 
        authenticateToken, 
        requireRole('super_admin'), 
        controller)

Create src/routes/auth.ts and 
src/controllers/authController.ts

POST /api/auth/login
  Body: { email: string, password: string }
  Logic:
    Find user by email in users table
    Check is_active = true, deleted_at IS NULL
    Compare password with bcrypt
    If valid: return accessToken, refreshToken, 
      and user object (id, email, role, 
      entityType, entityId)
    If invalid: return 401 with message 
      "Invalid credentials"

POST /api/auth/refresh
  Body: { refreshToken: string }
  Logic:
    Verify refreshToken with JWT_REFRESH_SECRET
    Look up user by id from token payload
    Check user still exists and is_active = true
    Generate new accessToken only (not new refreshToken)
    Return new accessToken

POST /api/auth/logout
  Protected: authenticateToken required
  Body: { refreshToken: string }
  Logic: 
    For prototype scope, just return 
    { success: true, message: 'Logged out' }
    Note in a comment that production would 
    maintain a token blacklist or refresh 
    token table

GET /api/auth/me
  Protected: authenticateToken required
  Returns: req.user payload (userId, role, 
    entityType, entityId)
