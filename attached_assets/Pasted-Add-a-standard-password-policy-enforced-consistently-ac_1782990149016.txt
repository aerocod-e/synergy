Add a standard password policy enforced consistently across the app, plus live validation feedback wherever a password is typed by the end user. Follow all steps in order.
Step 1, backend: shared password validation utility
Create artifacts/api-server/src/utils/passwordPolicy.ts exporting a single function:
tsexport function validatePassword(password: string): { valid: boolean; message?: string } {
  if (password.length < 6 || password.length > 15) {
    return { valid: false, message: 'Password must be between 6 and 15 characters.' };
  }
  if (!/[A-Z]/.test(password)) {
    return { valid: false, message: 'Password must include at least one uppercase letter.' };
  }
  if (!/[0-9]/.test(password)) {
    return { valid: false, message: 'Password must include at least one number.' };
  }
  if (!/[^A-Za-z0-9]/.test(password)) {
    return { valid: false, message: 'Password must include at least one special character.' };
  }
  return { valid: true };
}
Step 2, backend: apply it everywhere a password is set
Import and call validatePassword in each of these, returning 400 with the returned message if invalid, before any hashing or database write:

createUser in userController.ts, for every role
changePassword in authController.ts, for the new password field only, not the current password field
Confirm the Temp@1234 default used in resetUserPassword already satisfies the policy, it does, so no change needed there, but leave a short comment noting this so it is not accidentally changed to something that fails the new rule later

Remove the old separate 6-character and 8-character minimum checks wherever they exist, replace them with the single shared function so both endpoints enforce identical rules going forward.
Step 3, frontend: shared password rule checklist component
Create artifacts/mobile/components/PasswordRulesChecklist.tsx. It accepts a password: string prop and renders four rows, each with a checkmark or empty circle icon and a label:

At least one uppercase letter
At least one number
At least one special character

Each row turns green with a filled checkmark the moment its rule is satisfied by the current value of password, and stays gray with an empty circle otherwise. Recompute on every keystroke, this is a pure derived render, no debounce needed.
