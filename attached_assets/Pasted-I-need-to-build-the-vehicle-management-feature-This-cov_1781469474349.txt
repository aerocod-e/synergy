Step 2 -- Backend controller
Create artifacts/api-server/src/controllers/vehicleController.ts with these functions:
createVehicle -- POST handler. Accepts registration_number. Checks for an existing vehicle with the same registration number (including soft-deleted). If found active, returns 409. If found soft-deleted, reactivates it. Otherwise inserts a new row. Sets created_by to the calling user's id. Returns the created or reactivated vehicle.
searchVehicles -- GET handler for /vehicles/search?q=. Accepts a query string q. Returns all vehicles where registration_number ILIKE '%q%' and deleted_at IS NULL, ordered by closest match first. Returns up to 10 results. Used by the trip creation search dropdown.
listVehicles -- GET handler for /vehicles. Returns all active vehicles created by the calling Trip Admin (filter by created_by = req.user.id). Includes total trip count per vehicle by joining the trips table.
deleteVehicle -- DELETE handler. Soft deletes a vehicle by setting deleted_at = NOW(). Returns 400 if the vehicle has any active trips (status created or in_transit).
