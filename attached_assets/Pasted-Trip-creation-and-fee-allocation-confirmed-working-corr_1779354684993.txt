GET /api/wallets/my
Protected: authenticateToken
Allowed roles: admin only
Logic:
  Read req.user.entityType and req.user.entityId
  Find the wallet where:
    owner_type = entityType
    owner_id = entityId
  Return wallet with total_collected
  Return 404 if wallet not found

Response:
{
  "data": {
    "wallet": {
      "id": "...",
      "ownerType": "state" | "stakeholder",
      "ownerId": "...",
      "totalCollected": 0,
      "totalCollectedNaira": "0.00"
    }
  },
  "message": "Wallet retrieved"
}

Note: totalCollectedNaira is totalCollected 
divided by 100, formatted to 2 decimal places.
This is the ONLY place in the backend where 
kobo is converted to Naira. All other responses 
keep amounts in kobo.

GET /api/wallets/my/ledger
Protected: authenticateToken
Allowed roles: admin only
Query parameters (all optional):
  startDate: ISO date string (e.g. 2026-05-21)
  endDate: ISO date string
  feeType: 'loading' | 'unloading' | 
           'stakeholder_fee'
  page: number (default 1)
  limit: number (default 20, max 100)

Logic:
  Find wallet by req.user.entityType 
  and req.user.entityId
  
  Query wallet_ledger joined with trip_fees 
  and trips:
    WHERE wallet_ledger.wallet_id = wallet.id
    AND wallet_ledger entries ordered by 
        created_at DESC
    Apply date filter on wallet_ledger.created_at
    Apply feeType filter on trip_fees.fee_type
    Apply pagination

Response:
{
  "data": {
    "entries": [
      {
        "ledgerId": "...",
        "tripId": "...",
        "vehicleNumber": "...",
        "feeType": "loading" | "unloading" | 
                   "stakeholder_fee",
        "amount": 0,
        "amountNaira": "0.00",
        "entryType": "credit" | "reversal",
        "cleared": false,
        "clearedAt": null,
        "createdAt": "..."
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 20,
      "total": 0,
      "totalPages": 0
    },
    "summary": {
      "totalCredits": 0,
      "totalReversals": 0,
      "netTotal": 0
    }
  },
  "message": "Ledger retrieved"
}
