Fix 1 -- Vehicle plate badge stretching on short plates

In (tripadmin)/index.tsx, the plate badge container currently has flex: 1 which causes it to stretch across the full available width even for short plate numbers like "RIV-001-AA". This makes every plate badge the same width regardless of text length.

Fix: Remove flex: 1 from the plate badge container (plateBadge style). Instead give the outer row container flex: 1 with flexDirection: 'row' and alignItems: 'center'. The plate badge should have flexShrink: 1 and alignSelf: 'flex-start' so it hugs its text content. Keep numberOfLines={1} and ellipsizeMode="tail" on the text so long plates still truncate. The status badge should remain flexShrink: 0 with marginLeft: 8.

Apply the same fix to (superadmin)/trips.tsx if it uses the same plate badge pattern.

Fix 3 -- Stakeholder header iOS 26 system button style

Root cause confirmed: the stakeholder layout uses a Stack navigator while all other roles use Tabs. On iOS 26, React Navigation's Stack navigator renders the header using UINavigationBar under the hood, which iOS 26 automatically applies its liquid glass system chrome to. The Tabs navigator on the other three roles renders its own plain View header, bypassing iOS 26's system styling entirely -- this is why only the stakeholder is affected despite the screenOptions being identical.

Fix: In (stakeholder)/_layout.tsx, replace the Stack navigator with a Tabs navigator matching the exact pattern used in (tripadmin)/_layout.tsx. The stakeholder only has one screen (index) so there will be only one Tabs.Screen. Suppress the tab bar entirely since there is nothing to tab between -- do this by passing tabBar={() => null} to the Tabs component. Keep all screenOptions (headerStyle, headerTitleStyle, headerShadowVisible, headerRight with LogoutButton) exactly as they are -- do not change them.

The result should be a Tabs navigator with one screen, no visible tab bar, and a header that renders identically to the other three role screens.
