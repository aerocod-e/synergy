sqlCREATE TABLE IF NOT EXISTS pricing_charts (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  loading_fee     INTEGER NOT NULL,
  unloading_fee   INTEGER NOT NULL,
  is_active       BOOLEAN NOT NULL DEFAULT false,
  created_by      UUID REFERENCES users(id),
  created_at      TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
  updated_at      TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()

CREATE TABLE IF NOT EXISTS pricing_chart_stakeholder_rates (
  id               UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  pricing_chart_id UUID NOT NULL REFERENCES pricing_charts(id),
  stakeholder_id   UUID NOT NULL REFERENCES stakeholders(id),
  amount           INTEGER NOT NULL,
  created_at       TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
  updated_at       TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
  UNIQUE(pricing_chart_id, stakeholder_id)
);

Step 2 -- Backend controller
Create a new file at artifacts/api-server/src/controllers/pricingController.ts with four functions:
createPricingChart -- POST handler. Accepts loading_fee, unloading_fee, and stakeholder_rates (array of { stakeholder_id, amount }). All amounts arrive in kobo as integers. Inserts into pricing_charts with is_active = false, then inserts one row per stakeholder into pricing_chart_stakeholder_rates. Returns the created chart with its stakeholder rates.
updatePricingChart -- PUT handler. Accepts same body as create. Updates the chart row and upserts the stakeholder rates. Only allowed if the chart is not currently active.
getActivePricingChart -- GET handler. Returns the single chart where is_active = true, joined with all its stakeholder rates. Also join the stakeholder name from the stakeholders table. Returns 404 if no active chart exists.
activatePricingChart -- POST handler for /pricing/:id/activate. Sets the specified chart to is_active = true and sets all other charts to is_active = false. Returns the activated chart.
All amounts must remain as integers in kobo throughout -- no conversion to Naira in the backend.
